肉扎吉·亚森

我是肉扎吉·亚森。大约十年里主要做全栈开发：微信小程序、App、前端和后端都做过。现在更常做的事，是把中小企业里靠表格和群聊硬撑的流程，收成能上线、能追查的业务系统。

orhan.cn 用来记录开发、工具，以及真实项目里踩过的坑和做成的事。

现在主要在做什么

在新疆法商信息咨询有限公司，近期几件比较完整的事：

  • 企业签章小程序：原生微信小程序 + Rust Axum，把部门、员工、审批和电子签章放进同一套流程。复盘
  • 法律知识库：基于 RAG，用 Rust 和 Qdrant 做文档摄取、切片、向量化和带引用的检索问答，目前在律师行业内部试运行。进度记录
  • 巴扎摊位租赁管理：乡镇市场的摊位资产、租约和收款，做成可在现场用的小程序。复盘
  • 英吉沙小刀官网：国家级非遗相关项目，负责前端，把作品、传承人和内容展示跑通。复盘
  • 法律服务 App / 法商融合小程序：在线咨询、商户与律师入驻、人脸认证、钱包提现等；小程序已上线，App 已上华为应用市场。

几个项目串起来的判断，写在数字化怎么帮到企业里。

可以一起做什么

我目前在职，暂不主动找全职。远程、兼职或按项目合作可以聊。

比较合适的方向：

  • 业务向微信小程序与配套后台
  • Rust API（Axum 等）与现有系统对接
  • 官网、内容与溯源类站点
  • 轻量自动化部署与回滚（可参考 aynur-deploy）

不太适合的：只写页面没有业务边界的外包拼装，以及需要我承诺「上线就能涨多少量」的合作。
