我给 AI 做了个看板：helix-kanban

简单介绍 helix-kanban：一个使用 Markdown 存储、支持多项目和 MCP 的终端看板。

helix-kanban 是我用 Rust 写的终端看板，命令名是 hxk。想法很简单：AI 负责执行任务，我来安排任务；接入 MCP 后，AI 也可以直接读取待办、创建任务和更新状态。

任务保存在 Markdown 文件里#

helix-kanban 不需要单独运行服务，也没有远程账号。任务使用 Markdown 保存，项目配置使用 TOML 保存，可以直接查看、编辑或放进版本控制。

它同时支持全局项目和本地项目。全局项目放在 ~/.kanban/projects/，本地项目放在当前仓库的 .kanban/ 目录，适合让任务跟着代码一起走。

终端里的看板操作#

界面和快捷键参考了 Helix，可以用 h、j、k、l 在状态列和任务之间移动。任务较多时，可以放大当前状态列或调整列宽；也可以用模糊搜索和两字符标签快速跳转。

项目切换界面会列出全局项目与本地项目，并显示各自的任务进度。项目多起来后，可以直接搜索，不需要逐个翻找。

让 AI 一起维护看板#

hxk 内置了 MCP server，通过 hxk mcp 启动，可以接入 Codex、Claude Code 等支持 stdio MCP 的工具。AI 能列出项目和任务、创建或修改任务、移动状态，也可以一次创建多条待办。

安装了 Rust 工具链后，可以直接从 crates.io 安装：

cargo install helix-kanban --locked
hxk
