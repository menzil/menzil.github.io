Tmux 使用指南

tmux 终端复用器完整使用指南

什么是 Tmux#

Tmux (Terminal Multiplexer) 是一个终端复用器，允许你在一个终端窗口中运行多个会话，并且可以在后台保持运行。即使关闭 SSH 连接或终端窗口，tmux 会话也会继续运行。

基本操作#

会话管理#

# 创建新会话
tmux

# 创建命名会话
tmux new -s myproject

# 列出所有会话
tmux ls

# 连接到最近的会话
tmux attach

# 连接到指定会话
tmux attach -t myproject

# 杀死指定会话
tmux kill-session -t myproject

# 杀死所有会话
tmux kill-server

分离和重连#

# 在 tmux 会话中按快捷键分离
Ctrl+b d

# 或使用命令
tmux detach

常用场景#

1. 运行长期服务#

# 创建会话并启动开发服务器
tmux new -s dev
npm run dev

# 按 Ctrl+b d 分离会话
# 关闭终端窗口，服务继续运行

# 稍后重连
tmux attach -t dev

2. SSH 远程工作#

# SSH 连接到服务器
ssh user@server

# 创建或连接到 tmux 会话
tmux attach || tmux new -s work

# 即使 SSH 断开，工作也不会丢失

3. 多任务并行#

# 创建会话
tmux new -s multi

# 创建多个窗口
Ctrl+b c  # 窗口1: 编辑器
Ctrl+b c  # 窗口2: 服务器
Ctrl+b c  # 窗口3: 日志监控

# 在窗口间快速切换
Ctrl+b 0  # 切换到窗口0
Ctrl+b 1  # 切换到窗口1

配置文件#

创建 ~/.tmux.conf 自定义配置：

# 修改前缀键为 Ctrl+a（可选）
# set -g prefix C-a
# unbind C-b
# bind C-a send-prefix

# 启用鼠标支持
set -g mouse on

# 设置窗口和面板索引从 1 开始
set -g base-index 1
setw -g pane-base-index 1

# 增加历史记录行数
set -g history-limit 10000

# 快速重载配置
bind r source-file ~/.tmux.conf \; display "Config reloaded!"

# 更直观的分割快捷键
bind | split-window -h
bind - split-window -v

重载配置：

tmux source-file ~/.tmux.conf

Ctrl+b :

# 关闭
setw synchronize-panes off

保存会话布局#

使用 tmux-resurrect 插件可以保存和恢复会话：

# 安装 TPM (Tmux Plugin Manager)
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm

# 在 ~/.tmux.conf 中添加
set -g @plugin 'tmux-plugins/tpm'
set -g @plugin 'tmux-plugins/tmux-resurrect'

# 重载配置并安装插件
# Ctrl+b I (大写 I)

总结#

Tmux 的核心优势：

  • 会话持久化：关闭终端不影响运行
  • 多窗口管理：一个终端运行多个任务
  • 面板分割：同时查看多个输出
  • 远程工作：SSH 断开后可恢复

记住最重要的三个命令：

  1. tmux new -s name - 创建会话
  2. Ctrl+b d - 分离会话
  3. tmux attach -t name - 重连会话
